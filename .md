PHASE 6 — BACKUP & RESTORE SERVICE

6A. Create src/services/backupService.js.
- Export: exportAllData() and importAllData(file).

exportAllData():
- Opens every IndexedDB object store in the VitaChain database.
- Reads all records from each store.
- Serializes everything into a single JSON object keyed by store
name.
- Encrypts the JSON with AES‑256‑GCM using the user's existing
encryption key (from the health graph passphrase).
- Creates a downloadable Blob with the encrypted data saved as a
.vitachain file.
- Triggers the browser download.
- Shows a success toast: "Your health data has been backed up.
Keep this file safe."

importAllData(file):
- Reads the .vitachain file as an ArrayBuffer.
- Decrypts using the user's passphrase.
- Parses the JSON.
- Restores every record into its corresponding IndexedDB object
store, overwriting any existing data (with user confirmation).
- Shows a success toast: "Your health data has been restored."
- Reloads the app to reflect the restored data.

6B. Add Backup and Restore buttons to Settings → Export tab.
- Open src/pages/Settings.jsx (or the Export section).
- Add a "Backup Now" button (teal, with a download icon). On
tap, calls backupService.exportAllData().
- Add a "Restore from File" button (outlined, with an upload
icon). On tap, opens a file picker. After file selection,
calls backupService.importAllData(file).
- Both buttons display a loading spinner while processing.
- Both show a success/error toast after completion.
