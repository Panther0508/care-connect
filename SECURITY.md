# Security Policy

## Reporting a Vulnerability

To report a security vulnerability, please use one of the following methods:

1. **Email**: Send details to nmesirionyengbaronye@gmail.com
2. **GitHub Private Vulnerability Reporting**: Go to Settings → Security → Advisories → "Report a vulnerability"

Please include as much detail as possible, including steps to reproduce, affected versions, and any potential impact.

## Response Timeline

- **Acknowledgement**: We will acknowledge receipt of your report within 48 hours.
- **Initial Assessment**: Our team will perform an initial assessment within 5 business days to determine the validity and severity of the report.
- **Patch Development**: If confirmed, we will work on developing a patch. We aim to release a patch within 30 days of validation.

## Supported Versions

The following versions are currently receiving security updates:
- v0.x (pre-release versions)

## Disclosure Policy

We follow a coordinated disclosure model:
- We provide a 90-day deadline for vendors to develop and release patches after notification.
- After 90 days, if a patch is not yet available, we may publicly disclose the vulnerability to allow users to take protective measures.
- We will always give advance notice before public disclosure and work with reporters to ensure accurate information is shared.
